# Marigold phone wallet

The Marigold wallet for Android and iOS: one Expo app over the same Rust core as the desktop wallet. The core is built and released from [marigoldcash/marigold](https://github.com/marigoldcash/marigold) and arrives here as a prebuilt native module, so building the app needs Node and the platform tools, not Rust.

The plan is `PLAN.md`; which repository holds what is `docs/marigold/REPOS.md` in the node repository.
